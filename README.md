# vqa-system

> It's a VQA chat website that I worked on long before. It's now **archived**. The following content was generated by AI based on the project code to introduce what the project is supposed to do.

A lightweight Visual Question Answering (VQA) demo repository that provides
a simple web UI and minimal Python server to run VQA inference for development
and demonstration purposes.

Features
- Simple chat-style UI for asking questions about images.
- Minimal Python entrypoint and example job runner.
- Pre-configured static assets and HTML templates for fast demos.

Repository structure
- `job.py`: example runner for batched or scripted jobs
- `vqa-system.py`: main application entrypoint (web server)
- `resources/`: model and preprocessing configuration files
- `static/`: CSS, JS, and image assets used by the UI
- `templates/`: HTML templates (chat UI)

Quick start
1. Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python vqa-system.py
```

4. Open the printed address (e.g. http://localhost:5000) in your browser.

Requirements
- Python 3.8 or newer
- See `requirements.txt` for full dependency list
